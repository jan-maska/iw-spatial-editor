Built for real authoring work

Keep the data disciplined.

The editor separates the visual work of placing geometry from the bookkeeping required to keep a Spatial Context package structurally sound.

Locations, paths, and areas

Create and classify point locations, ordered roads and waterways, and polygonal area geometry from one shared canvas.

PointsPathsPolygons

Metric precision

Use logarithmic zoom from 1 m to 1 km per pixel, with default-on snapping to the format's 10 m coordinate resolution.

Calibrated references

Load a background map, set its world-space bounds and opacity, then trace without exporting the image into YAML.

Linked intersections

Move a location or linked path point and every matching X/Y intersection stays aligned while preserving its own elevation.

Selection that scales

Marquee across mixed geometry, add or remove from the selection, and move complete groups without changing relative positions.

Loss-aware YAML

Import the schema structures Spatial Context uses, retain fields the interface does not expose, and export both source files.

Two jobs, two formats

Keep authoring state.
Export clean sources.

The editor project and the Spatial Context sources serve different purposes. Keeping them separate makes the working file portable without adding editor-only data to runtime YAML.

  • Supports project migration
