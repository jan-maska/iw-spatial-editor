Spatial Editor quick guide

1. Set up the map
Choose Background, then enter its X/Y bounds in the Project inspector. The image is an editor reference and is never exported to YAML.
2. Draw the world
Use Location, Path, and Polygon. Finish paths and polygons with Enter, double-click, or the Finish button. Choose a Type and Subtype to classify and color every object.
3. Select and move
Drag across empty map space to select every intersecting object. Shift adds; Ctrl or Alt removes. Drag any selected object to move the complete selection while preserving relative positions.
4. Refine geometry
With one path or polygon selected, drag a vertex to move only that vertex. Double-click a boundary segment to insert one. Flip river paths so points run from source to mouth.
5. Snap precisely
The default 10 m snap grid matches the data format’s 0.01 km horizontal resolution. At maximum zoom, each snap interval is 10 pixels wide. Disable snapping only when intentionally inspecting or retaining finer imported coordinates.
6. Save and export
Save the complete .iwspatial project regularly. Validate, then export world-geography.yaml and world-spatial.yaml for the IW package.
Navigation
Mouse wheel zooms logarithmically across 0.001–1 km/pixel. Hold Space, use the Pan tool, or drag with the middle/right mouse button to pan. Ctrl/Cmd+Z undoes.
